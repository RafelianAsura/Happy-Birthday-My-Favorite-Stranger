# 🤍 Happy Birthday, My Favorite Stranger

A little birthday website made for someone who used to mean a lot — some things you remember don't really fade, even when the story's changed.

### 📖 About This Project
This is a personalized digital birthday gift, built as a small website instead of a regular card or message. It's a mix of memories, little things I still remember, and a few honest words I wanted to say properly.
